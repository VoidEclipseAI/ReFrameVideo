# ReFrameVideo 工作原理：从编辑到生成输入

下文的 Python 文件都在 `app/` 里。函数名以当前代码为准。

## 生成需要的材料

| 材料 | 内容 | 实现 |
|---|---|---|
| 粗剪视频 | 编辑后的画面；空区涂灰 128（可用背景图预填） | `roughcut.build()` 合成；`roughcut.guide_video()` 生成 `<Video 1>` |
| 重绘 mask | 随时间变化的重绘范围 | `regions.py` 逐帧分区，导出为 png 像素 mask |
| 参考图 | 首帧、尾帧、背景图、资料卡（用户选用的那张） | 作为参考图传入，不硬替换输出的首帧 |
| 提示词 | 编辑说明，Ref2VA 六段格式 | `prompt_format.py`、`repair_prompt.build()` |

## 整段生成的流程（ComfyUI）

1. 识别物体（SAM），再用图层做变换、改画幅、设重绘范围。这些都是确定性的编辑，不调用生成模型。
2. `generate.op_compose()` 调 `generate.prepare_compose()`：算出逐帧分区，合成粗剪和像素 mask，收集选用的参考图。
3. `repair_prompt.build()` 按空区分块写提示词。开启「空区分析」时，看图模型（默认 Qwen3-VL 8B；可选 Qwen3.5 9B 系列）对照粗剪和选用的首帧，逐块写补洞描述；关闭或没有选首尾帧时，用通用描述。
4. `engine.inpaint_levels()` 把视频和 mask 调整到 H3 需要的尺寸与帧数并上传；`engine.build_h3_graph()` 组装 ComfyUI 工作流。像素 mask 由自定义节点 `ReframeH3InpaintMask`（`comfyui/ComfyUI-Reframe/`）转成潜空间 mask：按 H3 的格子取最大值，格子里只要有一个重绘像素，整格都重绘。
5. 采样完成后，整幅模型输出保存为视频结果，沿用原片音轨。结果不做逐像素贴回，也不会自动触发后续步骤。

mask 是二值的：只有重绘与不重绘两种，没有软过渡。

## 云端 API 视频（可选）

`generate.op_api_video()` 走 `api_engine` 的异步任务，不经过 ComfyUI，也不做空区分析。它只发送三样东西：粗剪（空区涂灰）、面板里勾选的参考图、用户写的提示词原文。

个人测试中，云端视频模型目前不能稳定补全灰色空区：人形空区常被画成人，所以这条路径只作为实验选项。

## 为什么需要这些工具

分割、跟踪、遮挡处理、边缘修正、空区判定、参考图准备和版本管理，都是为了把编辑意图整理成模型能用的条件。输入的概念简单，但要让这些条件在整段视频里都合理，需要大量处理。

这条路线不做三维场景重建，也不提供三维重建那样的精确几何控制。它探索的是由二维编辑条件驱动的视频补全，不承诺恢复真实的场景结构。
