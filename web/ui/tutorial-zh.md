# ReFrameVideo 新手使用教程

本文面向使用者，假设软件、所需模型及服务已经配置完成，不是安装教程。

[English guide](tutorial-en.md)

## 先理解工作流程

ReFrameVideo 围绕一段视频工作：先识别主体，把主体变成可编辑图层；再移动、缩放或隐藏图层；用参考图告诉 AI 画面应该是什么样；最后生成新视频。

**导入视频 → 识别主体 → 编辑画面 → 生成并选用参考图 → 生成视频 → 检查结果。**

编辑时出现的棋盘格表示空区，不是成片效果。生成视频时才会补这些区域。

## 1. 打开软件，检查是否能生成

1. 在已配置好的软件目录双击 `start.bat`，或在该目录运行 `python start.py`。
2. 等待浏览器打开。默认前端地址为 `http://127.0.0.1:8765/`。
3. 使用期间保留启动窗口；关闭它会停止本次启动的服务。
4. 点右上角的齿轮「设置」，选择界面语言和外观。
5. 在「设置 → 服务连接」点「检查服务状态」。顶栏「ComfyUI 引擎」旁的小圆点：绿色 = 连得上，红色 = 连不上。若显示「假引擎」，只能测试界面，不能做真实生成。

如果使用的是管理员部署的服务，直接打开管理员提供的地址即可。ComfyUI 地址由部署者配置。云端 API 要你自己在「设置 → 云端 API」里按接口格式配一个平台，只用在图片生成、视频生成面板切到「API」的时候，不会替你配置 4090 上的 H3 视频服务。

## 2. 认识界面

| 位置 | 作用 |
|---|---|

| 视频编辑 | 识别、移动和调整视频图层 |
| 图片编辑 | 准备首帧、尾帧、背景图和人物资料卡 |
| 图片结果 | 查看候选图，并选一张供生成使用 |
| 视频结果 | 查看生成的视频 |
| 左侧工具栏 | 工具（选择、抓手、点选识别、画蒙版、逐帧修整）、视图、翻转和还原 |
| 右侧面板栏 | 图层、生成、蒙版、变换、画幅、版本、导出、历史 |
| 底部时间轴 | 播放、逐帧查看、选择时间范围 |
| 任务监控窗 | 查看运行状态、排队任务和运行日志 |

鼠标停在按钮或名称上，可以看到说明。参数不确定时先保留默认值，每次只调整一项。

右侧面板栏的图标可以随时切换。切换时，正在进行的临时操作会自动处理：画幅拖动会直接结束；点选识别会清掉选点；画蒙版如果已经画了东西，会先弹窗让你选择「建好再切换」、「丢掉」或「取消切换」；逐帧修整切走时会自动保存。

## 3. 第一课：把人物移到另一侧

### 第一步：导入视频

1. 点击顶部的「＋」，或按 `Ctrl+O`，打开「打开视频或项目」。
2. 填写视频文件路径后打开，或从「已有项目」里选择。
3. 视频超过 10 秒时，软件会问你用「分段编辑」还是「整段编辑」。第一次练习选「整段编辑」即可，长视频见第 6 节。
4. 等待预览帧准备完成，再播放检查视频是否正确。

路径必须是**运行后端的电脑能够访问的路径**。例如后端在另一台电脑时，不能直接使用你自己电脑上的路径。

### 第二步：识别人物

1. 打开右侧「图层」面板，找到「主体抠图识别」。
2. 选择识别方式：
   - 「文本提示」：输入英文名称，例如 `person`，SAM 3.1 会找出所有这类主体。
   - 「点选提示」：在画面上点要识别的主体（左键选中，右键排除不要的部分）。
3. 点「识别」，等待任务完成。
4. 如果识别出多个人，点击图层列表或画面，选中你想编辑的那个人。
5. 拖动时间轴检查开头、中间和结尾，确认选中的是正确人物，蒙版没有明显漏掉身体。

第一次练习选一段人物清晰、动作较慢的短视频。「帧范围」只限制识别的时间范围，不会裁剪后面所有操作。

### 第三步：移动人物

1. 在画面中选中人物，拖到目标位置。
2. 需要精确位置时，在「变换」里调整 X、Y、宽、高、旋转。
3. 人物原位置露出棋盘格是正常现象；这块空区需要生成时补背景。
4. 播放或逐帧检查，确保人物移动后没有跑出画幅。
5. 不满意可按 `Ctrl+Z` 撤销。

建议先只平移，不同时旋转、放大和扩画幅，便于判断每一步的效果。

### 第四步：准备首帧参考图

1. 点顶部页面栏的「＋」，选择「首帧」新建图片标签；如果已有，直接打开它。
2. 在「图片编辑」中检查首帧是否反映当前人物位置。画面过期时，点击重新取画面。
3. 在「生成」面板的「描述」里写出希望看到的画面，英文通常更适合。例如：

   > A person stands on the left side of the scene. Restore the background naturally in the empty area on the right.

   这只是左移人物的示例；请按实际位置、人物和场景改写。
4. 点「生成候选」。新手先出少量候选（例如 2–4 张），比较空区是否补全、人物是否变形、有没有多出人物。
5. 到「图片结果」点击满意的一张，确认出现「✓ 已选用」。**生成过候选不等于已选用。**
6. 若结尾画面变化明显，可以同样准备并选用「尾帧」。

如果还没有背景图，新建首帧或尾帧时软件会提醒你。先到「背景图」做一张（见第 6 节），首帧和背景会更对得上。

首帧、尾帧和背景图不是越多越好：先确保选用的图与当前编辑一致。之后如果移动人物、改画幅或改蒙版，旧候选会标记为「过期」，需要检查并重新生成。

### 第五步：生成视频

1. 返回「视频编辑」，打开右侧「生成」面板。
2. 顶部「视频生成用 ComfyUI 还是云端 API」默认是 ComfyUI（4090 上的 MiniMax H3 + LoRA）。
3. 检查「参考图」清单，确认本次会使用正确的首帧、尾帧或背景图（编号就是提示词里的 Picture N）。
4. 保留部署者提供的「模型」「LoRA」和「采样步数」（默认 20 步；用 Pika H3 Flex 加速 LoRA 时推荐 6 步）；不了解要求时不要随意更改。
5. 「输出分辨率」决定成片大小：「分辨率预设」选一档，「短边缩放」自己选短边，「自由分辨率」自己填宽高上限。成片就是 H3 直接生成的大小，比例始终跟画幅走。
6. 「用户提示词」推荐留空，「系统提示词」保持自动：软件会自动写好整段提示词。「空区分析」默认使用看图模型，会对照粗剪和首帧写出每个空区该补什么；选「不用」则使用通用描述（更快）。只有自动结果不对、需要补充画面里发生什么时，再在「用户提示词」里填写（英文效果最好）。
7. 点击「生成视频」，在任务监控里等待。生成耗时取决于模型、视频长度和硬件，约需几分钟到十几分钟。
8. 完成后打开「视频结果」。同样的输入加同一个 Seed，结果基本相同。

**云端 API：** 在「视频生成」顶部切到「API」，会直接调用你在设置里选的平台的视频模型。软件只发送粗剪（空的地方是灰色）、勾选的参考图和你写的提示词，不加其他句子。切换时会弹出提醒（目前 Seedance 无法完成视频补全，请慎重使用）；选「仍然使用 API」即可继续。API 模式不会运行本地的 H3 与 LoRA。

### 第六步：验收结果

至少检查开头、中间、结尾，以及人物经过遮挡或画面边缘的地方：

- 人物是否在预期位置，动作是否连续？
- 原位置是否补成合理背景，是否又出现一个人？
- 边缘是否闪烁、出现白边或断肢？
- 扩展区域是否有灰块、黑边或突然变化？

不满意时，先判断是识别、编辑还是参考图出了问题，再改对应步骤。不要一次把所有蒙版参数都调大。

## 4. 两个常用练习

### 去掉一个主体

1. 识别并选中目标图层。
2. 用图层行的眼睛按钮，或按 `H` **隐藏图层**，让它的位置成为空区。
3. 检查空区，再准备没有该主体的首帧参考图。
4. 选用候选，生成视频。

**不要用「删除图层」代替隐藏。** 删除图层会撤掉这层编辑，原视频中的主体可能重新露出来。如果模型总在原位置补出人形，可以在「蒙版」里把「原位置空区」的「空区形状」改为「矩形 ×3」，再检查参考图。

### 扩展画面两侧

1. 在右侧「画幅」里，选择比例（如 16:9、2.39:1），或直接在「每边往外扩多少」里填上下左右的像素（负数 = 裁掉）。也可以按 `F` 后直接在画面上拖画幅的边。
2. 检查画幅里斜线的部分：那是原视频没有的地方，生成时会补画。
3. 重新准备首帧，重点挑选扩展区域已经补完整的候选。
4. 必要时准备尾帧，再生成视频。

扩展后的首帧如果仍有灰块，不要期待视频生成一定会自动修好。先把参考图做好。

## 5. 蒙版和抠图参数什么时候才需要动

下面的控件大多在右侧「图层」或「蒙版」面板里。

| 控件 | 什么时候使用 |
|---|---|
| Alpha 视图（`A`） | 用黑底白色检查选中主体的抠图 |
| 主体抠图微调：收缩 / 扩展 | 微调主体轮廓；正值向外，负值向内 |
| 填充孔洞 | 抠图内部有小漏点 |
| 去除杂点 | 主体旁边出现零碎误识别区域 |
| 帧间平滑 | 抠图逐帧闪动；过大可能拖慢处理或让动作滞后 |
| 主体重绘范围：主体轮廓重绘 | 想在主体外面多重绘一圈（负数则让贴边的像素不贴上去） |
| 主体扩绘区 | 希望模型在主体某一侧补画，点 ＋ 添加，填像素或拖画面上的橙色箭头 |
| 补全被裁切部分 | 原视频边缘截断的主体移入画面后，需要补全截断处 |
| 空区形状 | 调整移走、隐藏主体后留下的空区形状 |
| 边界融合（全局）：融合带宽度 | 生成时让新画的部分和原画面衔接更自然（0 = 不加） |

「逐帧修整」（左工具栏）用画笔修这一帧的抠图，保存后还要检查相邻帧。「蒙版」里的「主体局部保留」可以在主体身上画一块保留范围，它跟着主体走。

图片编辑里的「本图」设置只作用于这一张参考图，不会改视频图层；图层的摆放仍然跟随视频。

## 6. 背景图、长视频、版本、导出与历史

**背景图：** 在图片编辑里新建「背景图」标签，先「提取背景」（从视频里扒出一张去掉主体的底图），再「补全背景」，选择合适的候选并选用。背景图可用于首帧和尾帧，也可以在蒙版的「空区预填背景」里让生成时用背景图填空区（仍会重绘）。改过画幅后，应重新提取背景，让它覆盖新增区域。

**长视频（分段编辑）：** 超过 10 秒的视频，可以选「分段编辑」：先按镜头自动切，太长的再平均切开。左边段号可以跳到某一段；每一段是一个独立项目，照常识别、编辑、生成。分段页里：
- 拖竖线调整切点，或在缩略图条上双击、按 `S` 添加切点（「＋ 添加切点」）。
- 「编辑这一段」才会为这一段建立项目；已经开始编辑的段改切点时，它的项目会先移到回收站，再按新范围重新剪。
- 「和下一段合并」去掉两段之间的切点。
- 「导出全片」：每段用你选的结果，没改的段用原视频，按顺序拼成全片。

**版本：** 右侧「版本」面板里，「＋」新建版本（复制当前版本，或从原视频新建）。做另一种方案前，先复制当前版本，这样可以保留两套图层编辑。每个版本行末尾的「⋯」可以改名、复制、在文件夹中显示或删除。删除版本会删掉它的视频和独占的文件，不能撤销，原视频不能删除；删除前先确认选中的版本。

**导出：** 右侧「导出」面板把某一步的素材打包成 zip 下载，里面有模型需要的图或视频、提示词和 ComfyUI 工作流，适合拿去自己的 ComfyUI 重跑：
- 「导出视频生成素材」：粗剪、遮罩、Picture 参考图、提示词和工作流。
- 「导出改图素材」：当前这张图的输入、遮罩、参考图和提示词。
- 图片结果（在「图片结果」页的「导出」面板里）：「下载选用的这张」直接下载选用的图；「打包选用的这张」「打包全部候选」下载 zip，附每张的提示词和参数。
- 视频结果（在「视频结果」页的「导出」面板里）：「下载这条视频」直接下载成片；「打包这条结果和素材」下载 zip，包含成片和当时交给 H3 的素材。

完整步骤见[导出到自己的 ComfyUI 运行](tutorial-comfyui-zh.md)。

导出的 zip 也会保存在项目文件夹的「导出export」里。AI 生成的成片在「视频结果」里查看；需要找文件时，用界面里的「在文件夹中显示」。项目文件夹的目录结构见[安装文档](../../docs/安装.md)第 9 节。

**历史：** 右侧「历史」面板列出每一步操作（来自项目里的操作记录）。改图层、改画幅的步骤可以「恢复到这步之前」；恢复本身也是一步，可以撤销。合并、删除、识别、生成只能查看。操作记录可以在「设置 → 性能」里关闭。

**所有结果：** 顶栏「所有结果」按钮列出所有项目生成过的视频和图片，按时间排列；可以按类型和项目筛选。点一个，直接跳到它所在的项目和结果页。

## 7. 常见问题

| 问题 | 先检查什么 |
|---|---|
| 点击生成没有得到真实视频 | 是否是假引擎（顶栏圆点是否绿色）；检查任务监控里的运行日志和模型服务 |
| 画面一直有棋盘格 | 当前是否仍是编辑预览；空区要在生成后才补 |
| 结果用了旧画面 | 候选是否过期；是否选用（✓ 已选用）；生成清单是否包含正确参考图 |
| 隐藏人物后又生成了一个人 | 首帧候选是否真的去人；检查空区形状（改成矩形 ×3）和背景参考 |
| 预览卡顿 | 在「设置 → 性能」降低「预览清晰度」，或在时间轴用「缓存整段」；改图层后需要重新缓存 |
| 切换右侧面板时弹出蒙版提示 | 画的蒙版还没确定：选「建好再切换」「丢掉」或「取消切换」 |
| 侧栏或任务窗位置乱了 | 设置 → 界面与帮助 → 恢复默认布局 |
| 英文界面仍有中文 | 自定义名称、用户输入和部分后端原始日志保留原文 |

## 8. 最常用快捷键

| 按键 | 操作 |
|---|---|
| `Ctrl+O` | 打开视频或项目 |
| 空格 | 播放／暂停；按住空格拖动可平移画面 |
| `,` / `.` | 上一帧／下一帧 |
| `I` / `O` | 设置时间范围的起点／终点 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 撤销／重做 |
| `H` | 隐藏／显示选中的图层；固定蒙版为启用／停用 |
| `Delete` / `Backspace` | 删除选中的图层（会先确认） |
| `M` / `A` | 显示重绘范围／Alpha 视图 |
| `F` | 编辑画幅 |
| `L` / `P` | 打开「图层」／「蒙版」面板 |
| `Shift+0` / `Shift+1` / `Shift+2` | 适应画幅／显示全部／适应选中 |
| `Ctrl+=` / `Ctrl+-` | 放大／缩小 |
| `C`（按住） | 临时看原视频 |
| `Esc` | 取消选中或退出当前浮层；具体编辑模式按界面提示 |

逐帧修整中：`B` 画笔、`E` 橡皮（按住 Alt 切换）、`W` 魔棒、`V` 移动、`[` `]` 调整大小、`,` `.` 换帧、`Enter` 保存、`Esc` 取消。

第一次练习的完成标准：能够独立完成「导入 → 识别 → 移动 → 选用首帧 → 生成 → 检查成片」。之后再学习背景图、分段编辑、复杂蒙版和多个版本。
