模型文件

同一个模型的不同量化版（bf16 / fp8 / int8 / nvfp4…）用同一个加载节点，直接选文件就行。默认文件不在 ComfyUI 上时，自动用同一模型的其他版本。GGUF 暂不支持。

首帧 / 尾帧还没有背景图

现在还没有可用的背景图。生成首帧 / 尾帧时，空出来的地方（移走的图层、画幅外）没法用背景图对齐，做出来的首尾帧可能和原视频对不上，生成视频时背景会出现不自然的突变。

建议先到「背景图」生成一张，再回来做首帧 / 尾帧。

视频生成切换到云端 API

测试中 Seedance 补空区不稳定：空的地方可能画出人形，或者保留灰色。仍要使用吗？

设置

通用

立即生效

性能

立即生效

只影响画布显示；生成和导出都用工作分辨率（见下）。

长片段分段页播放用的预览。改了以后，下次打开分段页时重做预览（短视频几秒，长视频要等一会）；不影响导出。

导入时视频长边超过它就先缩小，识别、蒙版、生成都按缩小后的视频算；原视频留在项目文件夹里。只影响之后新建的项目。

顶栏可以开多个项目标签；只有正在看的项目真正载入。常驻：切回最近那个项目不用重新载入，内存大约多占 1–4 GB。

缓存

可以随时清，重开项目时重算

抠图、分区、缩略图存在项目的「缓存cache」文件夹里，长期能到几 GB；清掉不影响项目、图层和生成结果，下次打开这个项目重新算一遍。

服务连接

云端 API

只给图片生成 / 视频生成面板的「API」用，其余都走 ComfyUI。软件不内置平台：照平台的接口文档，在下面「接口配置」里按三种格式之一填一份。效果不保证。

接口配置

format：openai_edits（OpenAI 改图，上传文件）/ json_sync（JSON 里放图、直接返回）/ async_task（提交拿任务号、再轮询；只有这种能做视频生成）。字段说明见 docs/安装.md「云端 API」。

界面与帮助

恢复侧栏宽度和任务窗位置，不改项目或生成设置。
